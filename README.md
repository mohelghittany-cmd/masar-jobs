# Masar | مسار الوظائف والهجرة

لوحة عربية لمتابعة فرص العمل في 16 دولة، والبحث في المصادر المجانية، وحفظ طلبات التوظيف داخل المتصفح فقط.

## التشغيل

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Actions → **Update jobs and publish Masar** → **Run workflow**.
3. افتح `https://mohelghittany-cmd.github.io/masar-jobs/` بعد نجاح النشر.

تحديث الوظائف مجدول يوميًا حوالي 08:17 بتوقيت دبي، لكن قد يتأخر أو يتوقف وفقًا لحدود GitHub. مصادر النتائج العامة محدودة؛ لا يوجد تحقق يدوي من كل وظيفة أو ضمان لتغطية كل دولة أو دعم تأشيرة. الموقع لا يرسل أي طلب توظيف بالنيابة عنك.

**الخصوصية:** بيانات التقديمات والملاحظات والروابط الخاصة تُحفظ في localStorage على جهازك فقط. لا ترفع السيرة الذاتية أو جواز السفر أو النسخ الاحتياطية إلى هذا المستودع العام. التصدير JSON غير مشفر.

مصادر النتائج: Arbeitnow وRemotive وJobicy (إذا كانت واجهاتها متاحة). كل إعلان يفتح رابط المصدر الأصلي.
